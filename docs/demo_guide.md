# 超市库存系统演示说明

## 一键准备

1. 执行数据库迁移：

```bash
python manage.py migrate
```

2. 生成演示数据：

```bash
python manage.py seed_demo_data
```

3. 启动后端与前端：

```bash
python manage.py runserver
```

```bash
npm run dev
```

4. 登录账号：

- `admin / 123456`
- `stock_admin / 123456`
- `finance / 123456`
- `cashier / 123456`

## 演示顺序

1. 登录系统，展示首页仪表板的商品数、库存记录数、低库存预警和月销售额。
2. 打开“商品管理”，说明商品、分类、供货商已接入真实接口。
3. 打开“库存管理”，重点展示低库存预警标签。
4. 对某个商品执行一次“入库”，返回列表后观察库存变化。
5. 再执行一次“出库”或“调整库存”，展示库存即时刷新。
6. 点击“查看记录”，展示该商品在当前仓库下的库存变动记录。
7. 打开“操作日志”，说明系统已记录创建、入库、出库、销售等关键动作。
8. 打开“销售分析”，展示销售额、订单数、毛利润、趋势表和热销商品。
9. 使用 `docs/cash_import_template.csv` 上传一份收银数据，说明导入后会生成销售记录并扣减库存。
10. 再次回到“库存管理”或“销售分析”，展示导入后的数据变化闭环。
